<h2 id="english">🇺🇸 About</h2>

I'm a Computer Engineer, developer, and technology enthusiast who has been building software since my teenage years.

I started programming on my own, self-taught, long before I knew exactly where it would take me. PHP was one of my first languages. Couple years later I was in a Computer Engineering program, and curiosity has been the constant ever since.Today, my work sits at the intersection of software engineering, cybersecurity, digital forensics, Artificial Inteligence and emerging technologies.

I enjoy understanding how things work — and then trying to build something better.

My professional path has taken me from developing and maintaining real-world information systems to working as a court-appointed forensic expert in technology and software-related cases. I currently work as a systems analyst in the public sector, and since mid-2024 I've been accredited by the Tribunal de Justiça do Paraná as a judicial and extrajudicial forensic expert, with a specialization I built over the past several years, on top of the same engineering foundation.

But I don't see these roles as who I am. They are simply different places where I get to apply what I am most interested in: **technology, engineering, problem-solving, and innovation.**

My personal projects tend to explore ideas around:

* 🔐 Cybersecurity, digital forensics and trustworthy computing
* 🤖 Artificial intelligence, local AI and AI agents
* 🧩 Software engineering and developer tools
* 🔎 Digital evidence, provenance and data integrity
* 🌐 Privacy and local-first architectures
* 🛠️ Open-source tools that solve practical problems

I particularly like projects where engineering meets something less obvious, where there is a difficult problem to understand, a system to design, or an idea that doesn't quite have a ready-made solution yet, and I like to make the result as useful as it is beautiful.

## Projects

### [PeritiaGo](https://github.com/athosbes/PeritiaGo)
The tool I actually use during court-ordered forensic collections. Single binary, hashing and an audit trail built in, made to hold up as evidence rather than just work on my machine. Grew out of an earlier Python toolkit, [peritia](https://github.com/athosbes/peritia).

If you're into Go, Windows internals, or want to help it run properly on Linux/macOS, the [issues](https://github.com/athosbes/PeritiaGo/issues) are open — genuinely happy to talk through ideas even if you're not sure where to start.

### [LocalPilot](https://github.com/athosbes/localpilot)
A Chrome extension for automating the internal, server-rendered web apps that never got an API — the JSF/PrimeFaces kind where every element id changes on every render. Record a flow or describe it in plain language, and it replays against the page's actual visible text, not a brittle selector. Runs on a local rule-based planner by default; nothing leaves the browser unless you explicitly point it at a model you host yourself.

### [Recall](https://github.com/athosbes/recall-extension)
A bookmark that remembers why you saved it. Captures the page plus the context — what it's for, the text you had selected, the note you left yourself — and lets you find it later by describing the problem instead of guessing the title. Everything lives in the browser's IndexedDB. No account, no server, no network calls.

### Smaller things
- [live-rtmp](https://github.com/athosbes/live-rtmp) — real-time video streaming through an Nginx RTMP server
- [camaracambe](https://github.com/athosbes/camaracambe) — search tool for public data from the Câmara Municipal de Cambé, built with DECO.CHAT
- [qrcode-pix](https://github.com/athosbes/qrcode-pix) — QR code generator for Brazil's PIX payment system
